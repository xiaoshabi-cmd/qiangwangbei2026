# 格攻击定量分析（hoRRibleRing）

## 1. 问题归约

单样本：`b = a·s + e (mod f)`，`s, e ∈ Z^512`，系数 ~ N(0, σ²)，σ = 3.371，`a` 均匀。

记 `M_a` 为"乘 a 再模 f"的 512×512 整矩阵（元素 ∈ [0,p)）。构造

```
L = { (y, x) ∈ Z^512 × Z^512 : x ≡ −M_a·y (mod p) }
  = { (y, −M_a·y + p·k) },        dim = 1024,   det = p^512
```

目标向量 `t = (0, b)`。若样本为 LWE，则存在 `v = (s, −M_a s + pk) ∈ L` 使

```
t − v = (−s, b − (−M_a s + pk)) = (−s, e) ,   ‖t − v‖ ≈ √2·σ·√512 = 107.9
```

⇒ 判定问题 = BDD（含唯一解码），或 Kannan 嵌入后的 uSVP（dim 1025）。

## 2. 判据与所需分块

```
det^(1/1024) = p^(1/2) = 31391
λ₁ ≈ GH = √(1024/2πe)·31391 = 2.43e5
gap = λ₁ / ‖(s,e)‖ = 243000 / 107.9 ≈ 2253
```

**gap 与维数几乎无关**：`gap ≈ p^½ / (σ·√(2πe)) = 31391/(3.371·4.133) ≈ 2253`。

- LLL 经验能力：`gap ≳ 1.02^d` ⇒ 仅当 `d ≤ ln(2253)/ln(1.02) ≈ 390`（n ≤ 195）。
- BKZ：需 `δ_β^1024 ≤ 2253`，用 δ_β = ((πβ)^{1/β}·β/(2πe))^{1/(2(β−1))} 反解：

| β | δ_β | δ_β^1024 | 与 2253 比较 |
|---|---|---|---|
| 60 | 1.01145 | 1.2e5 | 差 53× |
| 100 | 1.00926 | 1.3e4 | 差 5.8× |
| 120 | 1.00844 | 5.6e3 | 差 2.5× |
| 140 | 1.00776 | 2.8e3 | 差 1.2× |
| **150** | **1.00746** | **2.0e3** | **足够** |

代价：β = 150、d = 1025 ⇒ 单次 SVP（筛法）≈ 2^0.292·150 = 2^43.8，
BKZ 迭代约 8d ≈ 8200 次 ⇒ **~10^17 核操作 / 样本**，且需 336 次 ⇒ 不可行。
（fplll 用枚举而非筛法，只会更差。）

## 3. 实测标定（证明估算未偏悲观）

`scripts/cal.py`：用同一 p、σ，随机生成**可约** f（线性因子之积），植入已知 (s, e)，
构造同构的 Kannan 格（dim = 2n+1），用 FLINT `fmpz_mat.lll` 约化并检查是否回收：

| n | dim | 是否回收 | 耗时 |
|---|---|---|---|
| 16 | 33 | ✅ | 0.0 s |
| 32 | 65 | ✅ | 0.5 s |
| 64 | 129 | ✅ | 9.1 s |
| 128 | 257 | ✅ | 1742 s |
| 512 | 1025 | （不可行） | — |

判据预测：d=257 时需 gap ≥ 1.02^257 = 157 < 2253 ✅（与实测一致）；
d=1025 时需 gap ≥ 1.02^1025 = 4.4e9 ≫ 2253 ❌。**模型与实测吻合。**

## 4. 为什么无法"降维"（关键否定性结论）

### 4.1 信息论约束
未知量熵：`s, e` 共 1024 个高斯系数，每个约 3.80 bit ⇒ ≈ 10^1171 种可能。
商 `R/(h)`（deg h = D）给出 D 个 GF(p) 约束（每个 9.0 bit）⇒ 可行的必要条件是
`9D ≳ 1171` ⇒ **D ≳ 130**；若要求格上有可观 gap，需 D ≳ 200。

### 4.2 保小性约束（更强）
投影后 `e mod h = Σ_k e_k (x^k mod h)`。要它"小"，必须所有 `x^k mod h`（k < 512）系数小。
设 h 的整数提升的复根模长为 ρ，则系数按 ρ^k 增长；需 `ρ^511 ≪ p = 10^9` ⇒ **ρ ≲ 1.04**。
monic 多项式所有根模长 ≲ 1 的整系数情形 ⇒ 分圆多项式之积（Kronecker）。
而 f 无任何分圆因子（已用三种方法验证）⇒ **保小性商不存在**。

### 4.3 结论
用满 512 维（h = f，不降维）时 gap 达到最优 2253 —— 这就是为什么"horrible ring"
虽然高度可约，却**不能**帮助攻击者：小性在 CRT 基下被完全打散。
