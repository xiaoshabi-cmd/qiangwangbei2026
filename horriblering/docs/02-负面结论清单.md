## A. 样本/密钥侧

| # | 假设 | 检验方法 | 结果 | 脚本 |
|---|---|---|---|---|
| A1 | 所有 F0 共享同一 `s` 与同一 `e` | 对已知 LWE 样本两两计算 `(b_i−b_j)·(a_i−a_j)^{-1}`，看是否恒定 | 全部不同 ⇒ 不成立 | `hyp.py` / `x7.py` |
| A2 | 共享 `s`、独立 `e` | 同上；并用 55 个已知 F0 样本两两验算 max\|系数\| ≤ 30 | 无命中 | `x7.py` |
| A3 | `e = 0`（无噪声变体） | `b_i·a_j − b_j·a_i ≡ 0 ?`；以及 `a^{-1}·b` 是否小 | 系数 ≈ p/2 ⇒ 否 | `hyp.py` / `inv.py` / `x12.py` |
| A4 | `s = e`（同一采样器复用） | `b_i(a_j+1) − b_j(a_i+1) ≡ 0 ?` | 否 | `hyp.py` |
| A5 | `b = s·(a+c)` 型退化 | 对 c = 0,±1,±2,3 检验 `(a+c)^{-1}b` 是否小 | 否 | `inv.py` |
| A6 | `s`、`e` 支撑稀疏（如支撑 = 模 m 同余类 / 连续块） | 若 `\|supp s\|+\|supp e\| < 512` 则方程超定、可线性求解并判定 | 全部"不一致" ⇒ 支撑为全 512 维 | `x11.py` |
| A7 | b 的系数分布有偏 | 逐样本统计零系数、min/max、\|系数\|<1000 的个数 | 与均匀一致 | `analyze.py` |
| A8 | 样本中有重复 a/b 或异常样本 | 去重 + 逐样本 gcd(a_i, f) | 无重复；所有 a 与 f 互素 | `x1.py` |

|---|---|---|---|
| B1 | f 有分圆因子（`Φ_m`，m 小） | 根的乘法阶分布、`gcd(f, x^m ± 1)` | 无；根阶分布与随机一致 |
| B2 | f 有 `x^m − c`（c 小）型因子 | 幂序列 `θ^k` 常数命中扫描 | 0 命中（`sym4.py`） |

| B4 | 因子集在缩放 `x → cx` 下闭合 | c = 2,3,5,−2 及因子对上的 `c^{-d}g₁(cx) = g₂` 求解 | 0 命中（`x16.py`） |
| B5 | 因子集在反射 `x → c−x` 下闭合 | c = 0..30 | 仅 c = 0（即 −x 结构，deg 34） |

| B7 | 存在自互反因子 | 逐因子检查系数对称性 | 0 个 |

## C. 攻击方法侧（原理性封死，不只是"试过失败"）

| # | 方法 | 为什么不行 |
|---|---|---|
| C1 | CRT / 商环投影（投影到 deg ≤ 6 的因子） | 投影后 `s mod g`、`e mod g` 均**均匀** ⇒ `b mod g` 均匀，零信息。已数值验证（`proj1.py`：对 140 个根做 42 样本 LLL，全部无解） |
| C2 | 任意商 `R/(h)` 降维 | 要保"小性"需 `x^k mod h`（k<512）系数小 ⇒ 需 h 复根模长 ≲ 1.04 ⇒ 本质分圆 ⇒ f 无此类因子。**"保小性商"不存在** |
| C3 | 理想/零因子消元（找 c 使 `c·a ≡ 0`） | `a` 与 f 互素（所有样本已验证）⇒ 唯一解 c ≡ 0 |
| C4 | 对偶/线性泛函攻击（找 t 使 `⟨t,b⟩` 小） | 需 `⟨t, M_aᵀt⟩` 同时小 ⇒ 类 NTRU 的 dim-1024 SVP，所需 β≈210–250，**比原始格更差** |
| C5 | CRT 后按分量独立求解 | 未知量个数（2d/分量）> 方程数（d/分量），且无小性约束 ⇒ 恒可解，无判定力 |
| C6 | 只用 140 个 GF(p) 根的求值 | 信息论上勉强成立（熵计数 10^1171 vs p^140=10^1260），但格 gap 仅 ≈1.2 ⇒ 无法唯一解码 |
| C7 | Arora-Ge（噪声支撑小） | 512 个未知量、多项式次数 ~31 ⇒ 单项式 C(543,31) 爆炸 |
| C8 | BKW | 复杂度 ~2^{n/log n} = 2^57 量级 |
| C9 | 跨样本组合（`Σu_i·a_i ≡ 0` 抵消） | 各样本 `s_i` 独立 ⇒ `Σu_i a_i s_i` 无法抵消 |
| C10 | `pair_lattice.py`（假设 `b = m·s + e`，m 为标量） | 仅当 `a` 退化为标量时成立；实际 `a` 是满次数多项式 ⇒ **前提错误，勿再投入** |

## D. 关于"3 个 R"的记录

- 数据中唯一的非平凡"3"：**3 个偶四次自对称因子**（在 −x 下不变；其 GF(p⁴) 分量内
  Frobenius² 的作用为 x ↦ −x）。已考察对合、固定子域 F_{p²}、分量内 2×2 结构，**无收获**。
- 其余"3"均为平凡整除或巧合：336 = 3×112、42 = 3×14、261 = 3×87、512/3 ≈ 171（≈ 信息论阈值）。
- 两种读法：(a) 该结构是钥匙（用途未破）；(b) 提示只是说 flag 里也有 3 个 'R'（校验用），
  `:(` 表示作者自认提示无力。
