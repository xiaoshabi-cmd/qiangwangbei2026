## 1. 项目目标与背景

- 目标：从 336 个样本中恢复 42 字节 flag。
- 题目形态：`F0()` 产生 RLWE 样本 `(a, b = a·s + e mod f)`，`F1()` 产生均匀随机样本；
  按 flag 的二进制位选择，`0` → F0，`1` → F1。
- 环：`R = GF(p)[x]/(f)`，`p = 0x3ac01f87`，`deg f = 512`，噪声 `σ = 3.371`（离散高斯）。
- 题面提示（仅有的一句）：`Notice that there are 3 'R's in the title too :(`

**关键机制事实（决定全题难度）**：`F0()` 内部重新采样 `s` 与 `e`，
所以 336 个样本**互相独立**，每个 LWE 样本携带自己的新密钥。于是问题不是"用多样本恢复一个 s"，
而是"**对每个样本单独判定** b 是否落在 `a·B + B`（B = 小系数盒）中"。

## 2. 已完成的工作

### 2.1 数据与结构（已固化）

| 项 | 结果 |
|---|---|
| 样本数 | 336（⇒ flag 42 字节），a、b 均 512 个系数，无零系数、无重复 |
| f 的分解（mod p） | deg1=**140**, deg2=56, deg3=28, deg4=19, deg5=8, deg6=10，共 **261** 个因子，全部 deg ≤ 6 |
| f 在 Z 上 | 不可约（FLINT `fmpz_poly.factor`） |
| p 的算术 | p 素数；p−1 = 2·5·7·14080993；p+1 = 2³·3·41069563；p ≡ 7 (mod 8)，p ≡ 2 (mod 3) |
| 强异常 | 随机 512 次多项式期望只有 ~1 个线性因子；f 有 **140 个根** ⇒ 作者显式构造 |
| −x 对称部分 | `gcd(f(x), f(−x))` 次数 **34**：3 个偶四次自对称因子 + 5 对线性根对 (r,−r) + 1 对六次因子 |


### 2.3 已排除的假设（详见 `02-负面结论清单.md`，**请勿重复**）

### 2.4 定量难度模型（核心产出，详见 `03-格攻击定量分析.md`）

单样本判定 = 维数 1024 的 BDD：

| 量 | 值 |
|---|---|
| 格 `L = {(y,x) : x ≡ −M_a·y (mod p)}` | dim 1024，det = p^512 |
| λ₁ ≈ GH = √(1024/2πe)·p^½ | 2.43e5 |
| 目标向量 ‖(s,e)‖ = σ√1024 | 107.9 |
| **gap** | **≈ 2253**（与 n 几乎无关：p^½/(σ√(2πe))） |
| LLL 判据 gap ≥ 1.02^d | 仅当 **d ≤ 390**（n ≤ 195） |
| 所需 BKZ 分块 | **β ≈ 145–150** |

代价：β=150、d=1025，筛法单次 SVP ≈ 2^43.8，BKZ 约 8d≈8200 次 ⇒ **~10^17 核操作/样本**，
且需对 336 个样本重复 ⇒ 不可行。

"降维"为何不可能：任何环同态投影 `R → R/(h)` 都把"小盒"映成稠密集，
除非 h 的复根模长 ≲ 1.04（本质是分圆因子）；f 无分圆因子（已用阶、x^m±c、三项式三重检验），
故不存在保小性的商。信息论上还需要 `deg h > ~171`（= 512/3，这是数据里"3"的一个巧合来源），
而用满 512 维（h = f）时 gap 才达到最优的 2253。

## 3. 尚未解决的问题与风险

1. **主问题**：缺少可行的单样本判定算法。格路线需 BKZ-150，环境/算力都不支持。
2. **提示未破译**："3 个 R"。已确认数据中唯一的非平凡"3"结构 = 3 个偶四次自对称因子
   （其分量内 Frobenius² 作用为 x ↦ −x），但**未找到其攻击用途**；其余"3"（336=3×112、
   42=3×14、261=3×87、512/3≈171）均为平凡巧合。
3. **`pair_lattice.py` 分支无效**（前任探索）：它假设 `b = m·s + e`（m 为标量），
   而这只在 `a` 退化为标量时成立，实际 `a` 是满次数多项式 ⇒ 结构性不可能成功，**勿再投入**。
4. **数据可能与作者本意不符**：若作者本意是"共享 s"（把 `s` 定义在 `F0()` 外面），
   则实际数据仍按"每样本新密钥"生成，难度陡增。不能排除题目因此处于"作者以为可解、
   实际几乎不可解"的状态。
5. 无公开 writeup（中英文均已检索 `hoRRibleRing`），无法外部对标。
